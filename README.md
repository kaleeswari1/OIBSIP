# Landing Page — Web Development Internship

## Project Overview

This project is a responsive travel landing page developed as part of the Oasis Infobyte Internship Program under the Web Development and Designing track.

The landing page introduces travel destinations through a visually engaging layout, destination images, and a clear call to action.

## Technologies Used

- HTML5
- CSS3

## Features

- Attractive landing page layout
- Travel destination showcase
- Destination images
- Responsive styling
- Clear call-to-action section

## Project Files

- `index.html` — Main webpage structure
- `style.css` — Styling and layout
- `bgg.jpg` — Background image
- `munnar.jpg` — Munnar destination image
- `goa.jpg` — Goa destination image
- `ooty.jpg` — Ooty destination image

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
